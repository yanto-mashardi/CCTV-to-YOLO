# Setup (draft, not deployed)
1. Run server/preflight.sh on VPS; inspect existing services, firewall and ports. Do not stop or replace ETA-ETD. If ports conflict, use different host ports or audit existing MediaMTX before reusing it.
2. Confirm Docker Compose is installed. Copy server/mediamtx.yml.example to server/mediamtx.local.yml, replace all three placeholders with distinct strong URL-safe passwords. Never commit local configuration. Verify image tag and configuration compatibility in a local test first.
3. From server directory: docker compose -p cctv-yolo config; then only after approval docker compose -p cctv-yolo up -d. Check docker compose -p cctv-yolo logs. Allow TCP publisher/reader ports in provider and host firewall as appropriate. Restrict source IP when feasible; Docker published ports may bypass UFW. RTMP and RTSP are plaintext by request.
4. OBS custom server: rtmp://VPS:1935/live ; stream key bengkalis?user=bengkalis_pub&pass=PASSWORD. Larix URL: rtmp://VPS:1935/live/pakning?user=pakning_pub&pass=PASSWORD. Verify exact URL behavior for each publisher. VLC: rtsp://campus_reader:PASSWORD@VPS:8554/live/bengkalis (or live/pakning). Verify anonymous and wrong path denied.
5. Campus Windows: cd client; py -m venv .venv; .venv\Scripts\python -m pip install -r requirements.txt; copy config.example.json config.local.json. Set BENGKALIS_RTSP and PAKNING_RTSP to authenticated URLs. Set CCTV_GDRIVE_ARCHIVE to existing Google Drive Desktop archive folder; create simulation and observed subfolders. Run .venv\Scripts\python main.py --camera all.
6. Calibrate each normalized line and direction. Keep source_status SIMULATION for tests, OBSERVED only for verified live video.
7. See STORAGE.md for daily CSV, live JSON, rollover and restart recovery. Run python -m unittest test_storage test_counting. Track identity resets on reconnect; outages may miss crossings. Live stream and Drive cloud synchronization require validation.
8. No ETA-ETD integration. No video recording or YOLO on VPS. Rollback new standalone relay only: docker compose -p cctv-yolo down. Never use docker system prune or stop unrelated containers.
